# 性能基准记录（真实测量，非目标值）

> 运行：`npx vitest run tests/perf.bench.test.ts`（2026-11-24 实测）
> 环境：Windows，Node 22.22.2，jsdom（Vitest 3.2.7）。
> 说明：这是**前端渲染层**测量（虚拟化 + 默认折叠），不含 Tauri 窗口启动与 Python 进程开销。

## 事件规模 vs 渲染（折叠态）

| 事件数 | 折叠态渲染耗时 | DOM 过程行数 | 判定 |
|---|---|---|---|
| 50 | 12.8 ms | 3 | ✅ 首帧快 |
| 200 | 1.6 ms | 3 | ✅ 远低于 100ms 目标 |
| 1,000 | 1.3 ms | 3 | ✅ 无冻结 |
| 10,000 | 2.2 ms | 3 | ✅ 不建 1 万个组件 |

**关键结论**：DOM 行数恒定 3（实时区 3 条），与事件总数无关——
TanStack Virtual + 默认折叠生效，10,000 条历史不会一次性创建 UI 组件。
